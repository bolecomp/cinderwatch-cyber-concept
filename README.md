# Cinderwatch Cyber — Independent Concept

A fictional US cybersecurity and cyber-resilience website concept created for the BoleComp Digital portfolio.

## What is included

- Business-first cybersecurity homepage
- Interactive Downtime Exposure Calculator
- Fictional ransomware recovery scenario
- Fictional “before” website for an honest before/after comparison
- Responsive desktop and mobile layouts
- No forms, tracking, external APIs or data collection

## Open locally

Open dist/index.html in a browser. All routes and assets use relative paths, so the complete concept also works without a local server.

## Publish with Vercel

Import the GitHub repository as a new Vercel project and use:

- Framework Preset: Other
- Root Directory: ./
- Build Command: leave empty
- Output Directory: dist

Every push to the repository’s main branch will then create a new production deployment.

## Important disclosure

Cinderwatch Cyber is fictional. The company, figures, scenario and “before” website were created solely to demonstrate positioning, content architecture, conversion design and interactive UX. No client affiliation or performance claim is implied.
